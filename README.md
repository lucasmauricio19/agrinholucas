# Agro Forte, Futuro Sustentável

Este projeto foi desenvolvido para a competição Agrinho, com o objetivo de apresentar a importância do agronegócio sustentável, da tecnologia no campo e da preservação ambiental.

## Sobre o projeto

O site aborda temas relacionados ao campo, à sustentabilidade, aos desafios do agronegócio, às soluções para um futuro mais equilibrado e ao uso da tecnologia na produção rural.

A proposta é mostrar que o agro pode ser forte, produtivo e moderno sem deixar de respeitar o meio ambiente e os recursos naturais.

## Páginas do site

- **Início:** apresentação geral do tema.
- **Sustentabilidade:** importância da preservação do solo, da água e da biodiversidade.
- **Desafios:** principais dificuldades enfrentadas pelo agro.
- **Soluções:** alternativas sustentáveis para o futuro do campo.
- **Tecnologia:** inovação, agricultura digital e ferramentas modernas no agro.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- GitHub Pages

## Objetivo

O objetivo deste projeto é conscientizar sobre a importância de unir produção agrícola, responsabilidade ambiental, inovação e sustentabilidade.
